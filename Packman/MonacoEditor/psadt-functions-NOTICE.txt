License v3.0 (LGPL-3.0); the license texts are in Packman/PSADT/COPYING.Lesser and
Packman/PSADT/COPYING.GPL. This file is the derived data only; it is not changed by Packman except
for the added in_release / in_dev availability flags.

Packman/Tools/extract-psadt-functions.py regenerates the file from two PSAppDeployToolkit checkouts.
