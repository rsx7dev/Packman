# Concept 3 — Compact workstation

Palette: cool grey #EDF0F2, white, graphite #293138, amber #E8B45C and muted green. Embedded Instrument Sans and JetBrains Mono; 42px table rows, compact toolbar and a quiet inspector emphasize daily scanning. The six destinations and Applications controls follow the XAML. Neutral beautiful-shadows elevation is reserved for dialogs.

References: Awwwards for type hierarchy; CSS Design Awards for content/metadata separation; The FWA for compact grid divisions. Three reference captures and interaction screenshots are in `.orch/shots/`.

Baseline: read the shell, Applications, detail and workflow XAML plus UI-DESIGN.md. Browser captures of the repository’s existing UI images are in `out/design/current/`; live WPF execution was unavailable on Linux. All data and actions are local samples.

Checked 13 screens, hash fallback, Orchestra messages, search, filters, sorting, paging, selection, loading, dialogs and test-error feedback. No horizontal overflow at 1440px or 1280px. `desktop.png` is 1440 × 860; no mobile layout or production changes.
